# AardMiner 用户手册

## 概述

AardMiner 是一款 Windows 桌面应用，用于从 Excel 数据源汇总各业态（保险、商写、酒店）经营数据，并调用 DeepSeek API 进行 AI 分析，生成分析报告。

## 系统要求

- Windows 10 或更高版本（x64 / x86）
- Microsoft Excel（用于数据读写，不支持 WPS）
- 无需安装 Aardio 运行环境（exe 自带运行时）

## 安装

直接下载 `Publish/AardMiner.exe`，无需安装，双击即可运行。

## 首次配置

### 1. 准备数据目录

数据源目录需包含以下子文件夹：

```
数据源目录/
├── 经营报表/
│   ├── 盛唐融信.xlsx
│   ├── 君康经纪.xlsx
│   ├── 北京中言.xlsx
│   ├── 大连凯丹.xlsx
│   ├── 福建钱隆.xlsx
│   ├── 春夏秋冬.xlsx
│   ├── 重庆宜新.xlsx
│   ├── 伯豪瑞廷.xlsx
│   └── 重庆瑞尔.xlsx
└── 活动量/
    ├── 盛唐融信.xlsx
    ├── 君康经纪.xlsx
    ├── 北京中言.xlsx
    ├── 大连凯丹.xlsx
    ├── 福建钱隆.xlsx
    ├── 春夏秋冬.xlsx
    ├── 重庆宜新.xlsx
    ├── 伯豪瑞廷.xlsx
    └── 重庆瑞尔.xlsx
```

输出文件（如 `【2026年4月】经营数据.xlsx`）建议放在数据源目录下。

### 2. 配置 API Key

在 `%USERPROFILE%\.dskey` 文件中配置 DeepSeek API Key：

```
EXCEL=sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

以 `#` 开头的行视为注释。`EXCEL=` 大小写不敏感。

### 3. 编辑 project.toml

打开 `project.toml`（与 exe 同级），修改数据路径和月份：

```toml
[data]
source_path = "C:\Users\管理员\Desktop\2026年4月分析"
output_file = "C:\Users\管理员\Desktop\2026年4月分析\【2026年4月】经营数据.xlsx"

[report]
target_month = 4
target_year = 2026
```

详细配置项见 [配置参考](config-reference.md)。

## 界面说明

启动后界面分为三个区域：

![界面布局]

### 运行配置区

| 控件 | 说明 |
|------|------|
| 数据源目录 | 公司 Excel 报表所在文件夹，点击 `...` 选择 |
| 结果文件 | 汇总分析输出的 xlsx 文件，点击 `...` 选择 |
| 月份 | 报告月份（1-12），设为 0 则自动检测 |
| 年份 | 报告年份，设为 0 则自动检测 |
| 模型 | DeepSeek 模型名，默认 `deepseek-chat` |
| API Key | 显示 API Key 配置状态（已配置/未配置） |

### 执行控制区

三个按钮均独立可执行，但建议按顺序执行：

1. **数据汇总** — 从各公司原始报表汇总数据到输出文件
2. **业态分析** — 调用 AI 分析商写/保险/酒店三个板块
3. **公司分析** — 调用 AI 分析 9 家公司核心经营指标

### 运行日志区

实时显示执行进度和结果，格式为 `HH:MM:SS  内容`。日志区域自动滚动到最新内容。

## 使用流程

### 典型工作流

1. 准备好本月数据（经营报表 + 活动量文件放置在对应子目录下）
2. 在 `project.toml` 中设置数据源目录、输出文件、目标月份
3. 启动 AardMiner.exe
4. 检查配置是否正确：数据源、输出文件、月份年份、API Key 状态
5. 点击 **数据汇总**，等待完成
6. 点击 **业态分析**，等待 AI 分析完成
7. 点击 **公司分析**，等待逐公司分析完成
8. 打开输出文件查看结果

### 自动检测月份

当 `target_month = 0` 或 `target_year = 0` 时，系统按以下优先级自动检测：

1. 从输出文件的 **填写页** sheet 读取（A2 单元格=月份，A4=年份）
2. 从数据源目录名解析（如 `2026年4月分析` → 年份=2026，月份=4）
3. 回退到系统当前日期

### 部分执行

如果只改了某家公司数据，可以只执行对应阶段：

- **只做数据汇总**：仅更新数据，不做 AI 分析
- **只做业态分析**：前提是输出文件中已有汇总数据
- **只做公司分析**：前提是输出文件中已有汇总数据

## 执行结果

### 数据汇总结果

汇总数据写入输出文件的以下 Sheet：

| Sheet | 内容 |
|-------|------|
| 各公司名 | 经营报表（指标统计数据） |
| 保险类 | 人力、保费、续期、月度规模保费 |
| 商写类 | 面积、租赁、渠道/自营转化 |
| 酒店类 | 营销活动、OTA 评价、月均入住率 |

### AI 分析结果

| Sheet | 结果位置 | 内容 |
|-------|----------|------|
| 商写类 | L14 | 商写业态综合分析 |
| 保险类 | L14 | 保险业态对比分析 |
| 酒店类 | M14 | 酒店业态综合分析 |
| 各公司名 | C61 | 公司核心经营指标分析 |

每项分析结果包含质量评分（0-10 分），低于阈值的分析会附带质量提示。

## 常见问题

### Q: 启动后提示 "API Key: 未配置"

在 `%USERPROFILE%\.dskey` 文件中添加 `EXCEL=你的key`。常见错误：
- 文件路径错误：必须是 `C:\Users\你的用户名\.dskey`
- 格式错误：确保 `EXCEL=` 在一行的行首

### Q: 点击按钮后提示 "Excel 初始化失败"

需安装 Microsoft Office Excel。WPS 不兼容。

### Q: 数据汇总提示 "文件不存在"

检查 `project.toml` 中的 `source_path` 是否正确，以及该目录下是否有 `经营报表/` 和 `活动量/` 子文件夹，子文件夹中的文件名必须与公司名完全匹配（如 `盛唐融信.xlsx`）。

### Q: AI 分析提示 "未找到 Sheet"

输出文件中缺少对应的 Sheet。请使用正确的输出文件模板。

### Q: 只改了某家公司数据，需要全部重跑吗？

不需要。三个阶段都可以独立运行。改数据只影响数据汇总阶段。

### Q: 可以更换 AI 模型吗？

在 `project.toml` 的 `[analysis]` 节修改 `model` 配置项，或在界面中直接修改"模型"编辑框。支持所有 DeepSeek API 兼容模型（如 `deepseek-chat`、`deepseek-reasoner` 等）。
