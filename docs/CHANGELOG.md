## [0.0.1.0] (V0.6) — 2026-04

### 功能

- 三阶段执行流程：数据汇总 → 板块 AI 分析 → 公司 AI 分析
- 数据汇总：经营报表复制 + 三大业态（保险/商写/酒店）汇总
- 保险业态：人力、保费、续期、月度规模保费
- 商写业态：面积、租赁、渠道/自营转化
- 酒店业态：营销活动（三平台）+ 业务指标（OTA 评价、入住率）
- DeepSeek API 调用封装（指数退避重试、request/reasoning_content 兼容）
- 公司 AI 分析质量检查系统（五维度评分 0-10 分）
- 分批限流控制（批次大小 + 批次间延迟）
- UI 配置双向同步（编辑 → 保存 → 回填）
- 输出文件填写页自动更新（月份/年份写入 A2/A4）

### 配置

- `project.toml` 配置文件支持（TOML 手写解析器）
- API Key 从 `%USERPROFILE%\.dskey` 读取
- 公司列表 `companies.json`（三业态分组）
- Prompt 模板（四个 .md 文件，可覆盖）

### 技术基础设施

- Excel COM 封装层（打开/读写/粘贴/公式/格式）
- 公共工具库（数字提取、YTD 求和、月份自动检测）
- 配置多级回退（IDE → CWD → 上级目录）
- 资源文件多级加载（磁盘优先 → 内嵌回退）
